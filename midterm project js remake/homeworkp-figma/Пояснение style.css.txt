style.css — КОД И ОБЪЯСНЕНИЕ КАЖДОЙ СТРОКИ
==========================================

Сначала идёт настоящая строка из style.css, затем простое объяснение.
В CSS селектор выбирает элементы, а свойства внутри фигурных скобок меняют
их внешний вид. Точка перед словом выбирает class. Пустая строка лишь
разделяет правила.

001 | * {
Выбирает все элементы страницы. Звёздочка означает «всё».

002 |     box-sizing: border-box;
Меняет расчёт размеров: ширина элемента включает его содержимое, внутренние
отступы и рамку. box-sizing — способ считать размер; border-box — «рамка
внутри размера». Двоеточие отделяет настройку от значения, ; заканчивает её.

003 | }
Закрывает правило для всех элементов.

004 | [пустая строка]
Только разделяет правила.

005 | html {
Выбирает корневой HTML-элемент и начинает его оформление.

006 |     scroll-behavior: smooth;
Делает переходы прокрутки плавными. scroll-behavior — поведение прокрутки;
smooth — плавно.

007 | }
Закрывает правило html.

008 | [пустая строка]
Разделитель, браузер его пропускает.

009 | body {
Выбирает основную видимую часть страницы.

010 |     margin: 0;
Убирает внешний отступ страницы. margin — отступ снаружи; 0 — нулевой.

011 |     color: #20251b;
Задаёт основной цвет текста. color — цвет букв; #20251b — код тёмного цвета.

012 |     font-family: Arial, sans-serif;
Выбирает шрифт Arial. Если его нет, используется любой похожий шрифт без
засечек: sans-serif. Запятая разделяет основной и запасной варианты.

013 | }
Закрывает правило body.

014 | [пустая строка]
Разделяет правила.

015 | a {
Выбирает все ссылки сайта. a — HTML-тег ссылки.

016 |     color: inherit;
Цвет ссылки берётся у родителя. inherit означает «унаследовать».

017 |     text-decoration: none;
Убирает стандартное подчёркивание ссылки. none означает «нет».

018 | }
Закрывает правило ссылок.

020 | .header,
Выбирает класс header. Точка перед словом означает, что это CSS-класс.
Запятая говорит: следом будет ещё один селектор с теми же настройками.

021 | .footer {
Выбирает класс footer и начинает общее правило для header и footer.

022 |     display: flex;
Располагает вложенные элементы гибким способом, обычно в ряд. display задаёт
способ расположения; flex включает Flexbox.

023 |     align-items: center;
Выравнивает вложенные элементы по поперечной оси. center значит «по центру».

024 |     justify-content: space-between;
Распределяет элементы вдоль ряда, оставляя место между ними. space-between —
«пространство между».

025 |     padding: 20px 8%;
Задаёт внутренние отступы: 20 пикселей сверху/снизу и 8% ширины по бокам.
padding — отступ внутри элемента; px — пиксели; % — процент.

026 | }

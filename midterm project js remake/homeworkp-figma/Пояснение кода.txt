ШПАРГАЛКА К ЗАЩИТЕ ПОРТФОЛИО
============================

Не нужно заучивать весь код. Пойми, что делает сайт, запомни короткий рассказ
и несколько основных ответов. Построчное объяснение есть отдельно для каждого
файла: index.html, style.css и script.js.

ГОТОВЫЙ РАССКАЗ НА ЗАЩИТЕ
-------------------------

«Это одностраничное портфолио. В нём есть приветствие, информация обо мне,
этапы моей работы, карточки проектов и контакты. HTML создаёт структуру
страницы. CSS отвечает за цвета, расположение и отображение на телефоне.
JavaScript добавляет действия: переключение темы, фильтр проектов,
автоматический год в подвале и плавную прокрутку наверх».

Если попросят показать сайт, пройди по нему сверху вниз и назови разделы.
Затем покажи кнопку темы, фильтры проектов и ссылку наверх.

ТРИ ФАЙЛА — ТРИ ЗАДАЧИ
----------------------

index.html — содержание: заголовки, абзацы, картинки, ссылки и кнопки.
Представь его как скелет или план страницы.

style.css — внешний вид: цвета, шрифты, отступы, карточки и расположение.
Это оформление скелета.

script.js — действия: что происходит после нажатия кнопок и загрузки страницы.

КАКИЕ СЛОВА НАДО ЗНАТЬ
----------------------

Тег — элемент разметки в угловых скобках, например <p>.
Атрибут — дополнительная настройка внутри тега, например href="#about".
class — имя, по которому CSS оформляет элементы; один класс может повторяться.
id — метка одного конкретного элемента; по ней можно перейти к разделу.

div — обычная «коробка», группирует элементы.
nav — коробка специально для меню.
section — отдельный тематический раздел.
a — ссылка.
button — кнопка действия.
p — абзац; h1/h2/h3 — заголовки разных уровней.

В CSS точка выбирает класс: .card. Знак # выбирает id: #projects.
В CSS margin — отступ снаружи элемента, padding — отступ внутри.
Flex и Grid — способы располагать блоки.
@media — правила, которые меняют вид страницы на узком экране.

В JavaScript функция — набор команд для действия. Обработчик события запускает
функцию, когда человек нажимает кнопку. document.querySelector ищет элемент,
а addEventListener назначает реакцию.

КАК РАБОТАЮТ ЧЕТЫРЕ ДЕЙСТВИЯ
----------------------------

Тёмная тема:
При нажатии JavaScript добавляет или убирает класс dark-theme у body.
CSS содержит правила, которые меняют цвета, когда этот класс включён.

Фильтр проектов:
У каждой кнопки есть data-filter, у каждой карточки — data-category.
JavaScript сравнивает значения. Совпала категория — карточка видна,
не совпала — скрыта.

Год:
JavaScript берёт текущий год и вставляет его в пустое место в подвале.

Прокрутка наверх:
При нажатии отменяется обычный переход ссылки, после чего JavaScript плавно
прокручивает страницу к началу.

ВОПРОСЫ, КОТОРЫЕ МОГУТ СПРОСИТЬ
--------------------------------

Что такое HTML?
Язык разметки, который задаёт структуру и содержимое страницы.

Что такое CSS?
Язык стилей, который отвечает за внешний вид и расположение.

Для чего здесь JavaScript?
Он добавляет интерактивность: тему, фильтр, текущий год и прокрутку.

Чем div отличается от nav?
div — универсальная группа. nav обозначает группу ссылок меню.

Чем class отличается от id?
class можно назначить нескольким элементам. id обозначает один элемент.

Почему сайт подходит для телефона?
В CSS есть @media: при узком экране сетки меняют число колонок и отступы.

Как фильтр понимает, какие проекты показать?
Сравнивает категорию нажатой кнопки с категорией каждой карточки.

Что делает const?
Создаёт переменную, которой нельзя присвоить другое значение. Это не значит,
что нельзя менять свойства объекта, который хранится в переменной.

Чем = отличается от ===?
= присваивает значение. === сравнивает два значения.

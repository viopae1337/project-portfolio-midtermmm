script.js — КОД И ОБЪЯСНЕНИЕ КАЖДОЙ СТРОКИ
==========================================

Сначала показана настоящая строка программы, ниже — простое объяснение.
Точка между словами означает «взять часть объекта». Круглые скобки вызывают
действие или передают ему данные. Пустые строки ничего не делают.

001 | function toggleTheme() {
Объявляет функцию — команду для переключения темы. function значит «функция»,
toggleTheme — придуманное имя, круглые скобки означают, что входные данные
не нужны, { начинает команды этой функции.

002 |     document.body.classList.toggle("dark-theme");
Находит список классов у всей страницы и переключает dark-theme: если класса
нет — добавляет, если есть — убирает. document — страница, body — её видимая
часть, classList — список классов, toggle — переключить. Точка означает
«взять свойство/действие у предыдущего объекта».

003 | }
Закрывает функцию toggleTheme. Фигурная скобка } показывает, что её команды
закончились.

004 | [пустая строка]
Только разделяет функции.

005 | function filterProjects(category) {
Объявляет функцию фильтра проектов. category — входное значение, то есть
категория, которую выбрал пользователь. { начинает команды функции.

006 |     const projects = document.querySelectorAll(".project");
Ищет все карточки класса project и сохраняет их в переменную projects.
const создаёт переменную; document — HTML-страница; querySelectorAll —
«найти все»; точка в ".project" означает, что ищется CSS-класс project.
Знак = сохраняет результат поиска в переменную.

007 | [пустая строка]
Разделяет команды для удобства чтения.

008 |     projects.forEach((project) => {
Запускает вложенную команду отдельно для каждой карточки. forEach значит
«для каждого»; project — имя текущей карточки; стрелка => начинает короткую
функцию; { открывает её команды.

009 |         const matchesCategory = category === "all" || project.dataset.category === category;
Проверяет, подходит ли текущая карточка. matchesCategory хранит ответ
«да/нет». === означает «равно ли»; "all" — показать всё; || означает «или»;
dataset.category читает категорию карточки из HTML data-category.
Строка верна, если выбран показ всех проектов ИЛИ категория карточки совпала
с выбранной категорией.

010 |         project.hidden = !matchesCategory;
Скрывает неподходящую карточку и показывает подходящую. hidden управляет
скрытием; = записывает значение; ! значит «не», то есть переворачивает
результат проверки. Если совпадения нет, hidden станет true — скрыть.

011 |     });
Заканчивает короткую функцию для одной карточки и вызов forEach для всего списка.
} закрывает блок, ) закрывает вызов, ; завершает команду.

012 | }
Закрывает функцию filterProjects.

013 | [пустая строка]
Разделяет функции.

014 | function showCurrentYear() {
Объявляет функцию вставки года. showCurrentYear — имя «показать текущий год».
{ начинает команды функции.

015 |     const yearElement = document.querySelector("#current-year");
Находит элемент с id="current-year" и сохраняет его в yearElement. querySelector
ищет один элемент; # в "#current-year" означает поиск по id; const создаёт
переменную; = сохраняет найденный элемент.

016 |     yearElement.textContent = new Date().getFullYear();
Записывает текущий год внутрь найденного HTML-элемента. textContent — текст
элемента; new Date() получает текущую дату; getFullYear() берёт из неё год;
= записывает год в textContent.

017 | }
Закрывает функцию showCurrentYear.

018 | [пустая строка]
Разделяет функции.

019 | function scrollToTop() {
Объявляет функцию прокрутки к началу страницы. scrollToTop значит «прокрутить
наверх»; { начинает её команды.

020 |     window.scrollTo({ top: 0, behavior: "smooth" });
Просит браузер плавно прокрутить страницу к самому верху. window — окно браузера;
scrollTo — прокрутить; фигурные скобки содержат настройки; top: 0 — верхняя
позиция; behavior: "smooth" — плавное движение.

021 | }
Закрывает функцию scrollToTop.

022 | [пустая строка]
Отделяет функции от подключения действий к кнопкам.

023 | document.querySelector("#theme-toggle").addEventListener("click", toggleTheme);
Находит кнопку темы и назначает ей действие при нажатии. "#theme-toggle" —
поиск элемента по id; addEventListener — «слушать событие»; "click" — нажатие;
toggleTheme — функция, которую надо запустить при нажатии. Скобок после имени
функции нет, потому что передаём её браузеру для будущего запуска.

024 | [пустая строка]
Разделяет обработчики.

025 | document.querySelectorAll(".project-filters button").forEach((button) => {
Находит все кнопки внутри блока фильтров и настраивает каждую. Точка в
".project-filters" ищет класс; пробел означает «внутри»; button без точки —
HTML-тег кнопки; forEach повторяет действие для каждой; button — текущая кнопка.

026 |     button.addEventListener("click", () => filterProjects(button.dataset.filter));
Говорит: при нажатии на эту кнопку вызвать фильтр с её категорией.
button — текущая кнопка; addEventListener слушает событие; "click" — нажатие;
() => — короткая функция, запускаемая позже; dataset.filter читает значение
data-filter из HTML и передаёт его в filterProjects.

027 | });
Закрывает функцию настройки кнопок и заканчивает forEach.

028 | [пустая строка]
Разделяет обработчики.

029 | document.querySelector("#back-to-top").addEventListener("click", (event) => {
Находит ссылку наверх и добавляет действие на нажатие. "#back-to-top" ищет id;
addEventListener ждёт событие; "click" — нажатие; event — данные о нажатии,
которые браузер передаст функции; { начинает команды обработчика.

030 |     event.preventDefault();
Отменяет обычное поведение ссылки. preventDefault значит «предотвратить действие
по умолчанию»: вместо обычного перехода ниже будет запущена своя прокрутка.

031 |     scrollToTop();
Запускает функцию плавной прокрутки наверх. Скобки () означают «выполнить сейчас».

032 | });
Закрывает функцию-обработчик нажатия и вызов addEventListener.

033 | [пустая строка]
Отделяет обработчики от последней команды.

034 | showCurrentYear();
Сразу запускает функцию, которая вставляет год в подвал. Скобки означают вызов.

КАК ПОНЯТЬ РАБОТУ ФИЛЬТРА НА ПРИМЕРЕ
------------------------------------

На кнопке «Сайты» в HTML стоит data-filter="web".
На карточке сайта стоит data-category="web".
JavaScript читает оба слова web и сравнивает их. Они равны — карточка видна.
У остальных карточек категория другая, поэтому они скрываются.

КАК ПОНЯТЬ РАБОТУ ТЕМЫ
----------------------

Кнопка вызывает toggleTheme. Эта функция переключает класс dark-theme у body.
CSS содержит отдельные правила для этого класса, поэтому цвета страницы меняются.

index.html — КОД И ОБЪЯСНЕНИЕ КАЖДОЙ СТРОКИ
===========================================

Как читать: сначала дана настоящая строка из index.html, сразу под ней —
простое объяснение. Внутри пояснения разобраны важные слова этой строки.
Текст в кавычках — значение настройки. Текст между тегами — то, что увидит
человек на странице.

001 | <!DOCTYPE html>
Сообщает браузеру: «это современный HTML». DOCTYPE — объявление типа документа;
оно не является обычным элементом и не показывается на странице.

002 | <html lang="ru">
Открывает весь HTML-документ. html — корневая оболочка страницы. lang — язык,
ru означает русский. В конце документа есть закрывающий </html>.

003 | <head>
Открывает блок настроек страницы. head — «голова»: здесь задают настройки
вкладки и подключают CSS; это не основной текст сайта.

004 |     <meta charset="UTF-8">
Задаёт кодировку текста. meta — служебная настройка; charset означает
«кодировка символов»; UTF-8 помогает браузеру правильно показывать русский.
У meta нет отдельного закрывающего тега.

005 |     <meta name="viewport" content="width=device-width, initial-scale=1.0">
Настраивает страницу для экрана телефона. viewport — видимая область экрана;
width=device-width просит использовать ширину устройства; initial-scale=1.0
задаёт начальный масштаб. Запятая разделяет две настройки.

006 |     <title>Нурэль — моё портфолио</title>
Задаёт название вкладки браузера. title — «название»; слова между тегами —
это само название. </title> закрывает элемент.

007 |     <link rel="stylesheet" href="style.css">
Подключает оформление из style.css. link подключает файл; rel="stylesheet"
говорит, что это таблица стилей; href — путь к файлу. Тег link не закрывается
отдельным тегом.

008 | </head>
Закрывает блок настроек head. Символ / означает «закрыть».

009 | <body>
Открывает видимую часть страницы. body — «тело», то есть всё основное
содержимое сайта.

010 |     <header class="header" id="top">
Начинает шапку сайта. header — верхняя вводная часть; class="header" даёт CSS
имя для оформления; id="top" создаёт метку «верх», куда можно перейти ссылкой.

011 |         <a class="logo" href="#top">Нурэль.</a>
Создаёт имя-ссылку на начало страницы. a — ссылка; class="logo" задаёт ей вид;
href — адрес; #top означает перейти к элементу с id="top". Текст между тегами
виден посетителю.

012 |         <nav>
Начинает меню. nav — сокращение от navigation, то есть «навигация»; внутри
него находятся ссылки меню и кнопка.

013 |             <a href="#about">Обо мне</a>
Создаёт ссылку на раздел обо мне. href="#about" ищет элемент с id="about";
«Обо мне» — подпись, которую видит посетитель.

014 |             <a href="#process">Процесс</a>
Создаёт ссылку на раздел процесса работы. #process должен совпасть
с id="process" у целевого раздела.

015 |             <a href="#projects">Проекты</a>
Создаёт ссылку на проекты. #projects указывает на раздел с id="projects".

016 |             <a href="#contact">Контакты</a>
Создаёт ссылку на контакты. #contact указывает на id="contact".

017 |             <button class="theme-toggle" id="theme-toggle" type="button">Сменить тему</button>
Создаёт нажимаемую кнопку смены темы. button — кнопка; class задаёт оформление;
id позволяет JavaScript найти именно её; type="button" означает обычную
кнопку. «Сменить тему» — текст на кнопке.
